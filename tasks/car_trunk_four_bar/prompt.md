# Working car trunk four-bar linkage

Build a mechanically coherent, animated car-trunk hinge demonstrator in Blender. The four rigid links are the fixed body bracket A-B, input link A-C, trunk-lid coupler C-D, and follower B-D. Use the exact pivot coordinates, link lengths, assembly branch, and animation range in the supplied design brief.

The saved `.blend` must visibly communicate how the mechanism works and must remain within the declared bounds. It must contain a non-empty collection named `MODEL`, plus exact-position objects named `ANCHOR_fixed_rear_pivot` and `ANCHOR_fixed_front_pivot`. Include the complete closed-to-open animation and save the working file inside the supplied workspace.

Create an auditable kinematic validation report, register it as evidence, and create a checkpoint after the fully rigged mechanism is ready for review. Use front, right, top, and azimuth_045 checkpoint views. Do not submit the final result until that checkpoint has completed and any pending human feedback has been handled.
